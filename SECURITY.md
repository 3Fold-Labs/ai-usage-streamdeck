# Security

Only the latest preview release is maintained. See [connection details](docs/CONNECTIONS.md) for local files, credential flow, endpoint, and optional Claude settings changes.

Report vulnerabilities through the repository's **Security → Report a vulnerability** feature when available. If private reporting is unavailable, open a non-sensitive issue asking a maintainer for a private reporting channel. Do not post tokens, app credential files, account identifiers, or private screenshots in issues.

Include plugin, Windows, and Stream Deck versions, the affected provider, and a minimal reproduction using synthetic data. Report credential handling flaws or unexpected network destinations privately.
